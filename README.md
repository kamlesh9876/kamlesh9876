## 🧠 About Me

I'm a Computer Science Engineering developer focused on building backend systems, AI-powered applications, REST APIs, and full-stack products.

My primary focus is **Python backend development, FastAPI, REST APIs, databases, LLM applications, RAG systems, and real-time applications**. I take ideas from problem definition and architecture through backend development, database design, AI integration, frontend development, testing, and deployment.

I've worked with FastAPI, Flask, Django, React, Node.js, and Express.js, along with relational and NoSQL databases — and I'm especially drawn to the intersection of backend engineering and AI: Large Language Models, Retrieval-Augmented Generation, semantic search, document processing, and intelligent automation.

I learn primarily by **building, debugging, experimenting, and improving real projects.**
